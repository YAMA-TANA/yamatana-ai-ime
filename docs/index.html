HOW IT WORKS

Mozcはそのまま。
候補の順番だけ、AIが見直します。

文章そのものを生成するAIではありません。Mozcが作った候補を受け取り、その場の文脈に合いそうなものを上に持ってくる仕組みです。

↕

Mozcの候補を並べ替える

通常のかな漢字変換をMozcに任せ、その候補をAIが再評価します。AI側で問題が起きた場合はMozcの候補をそのまま使います。

⌂

文章を外へ送らない

入力した文章や前後の文脈は、ローカルの推論にだけ使います。外部のAI APIやテレメトリへの送信は行いません。

⚡

310Mから70Mへ

IME向けに調整した310Mモデルをteacherとして、70Mのstudentへ蒸留しました。CPUではINT8、対応GPUではDirectML FP16で動きます。

▤

候補はまとめて採点

Mozcの候補を一つずつ処理するのではなく、候補リスト全体を1バッチにまとめてONNX Runtimeへ渡します。

MODEL SIZE

モデルを小さくして、
普段使いしやすくしました。

初期の310M版は精度は高い一方、IMEとして配るには少し重めでした。v2では70Mへ蒸留し、CPU用モデルを約318MBから約68MBまで縮めています。

PRIVACY

変換のために、文章をクラウドへ送る必要はありません。

AIモデルはPC上で動きます。入力内容や前後の文脈を外部のAIサービスへ送信しません。モデル自体にも通信機能はありません。

    MSIをインストール

    Win + Spaceで選択

  3. 03
    使いたい時だけAIをON

    通知領域のYamatanaアイコンから有効にします。初期状態はOFFです。
