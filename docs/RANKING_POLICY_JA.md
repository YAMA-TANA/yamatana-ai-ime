# AI候補順位の計算と校正

## AIへ渡す文脈

設定値の上限（既定128文字）まで取得した後、改行、句点、疑問符、感嘆符、全角空白を文境界として、変換対象を含む現在の一文だけを使う。読点は同じ文の情報なので切らない。

例：

```text
取得文脈: 彼の顔の鼻は大きい　庭には美しい____
使用文脈:                         庭には美しい____
```

これにより、前の文の「顔・鼻」が次の文の「はな」判定へ混入しない。文脈依存の実務フレーム補正（`context_bonus`）は、この文境界切り出し後の採点段階で別途適用する。

## 採点式

AIで比較するのは、Mozcの表示候補を表記で重複除去した先頭8表記である。表示候補そのものは削除しない。AIが返した代表表記だけを先頭側へ並べ、比較対象外の候補と重複候補は相対順を維持する。

```text
evidence = model_score + style_bonus + context_bonus
           - lexical_penalty - reading_identity_penalty
final    = evidence - 0.22 × ln(1 + Mozcの0始まり順位)
```

- `model_score`: 前後文脈と候補をONNXモデルへ同時入力した素点。
- `style_bonus`: 同じ意味の漢数字候補も存在するとき、算用数字表記へ`1.00`点。例：`一位`と`1位`。
- `context_bonus`: 明確な実務フレーム（例：購入申請→決裁、法改正→規程）への方向補正。候補説明に加点理由を残す。
- `lexical_penalty`: 読み辞書に有効語が存在するのに候補が未知語なら`1.50`点。
- `reading_identity_penalty`: Mozcに漢字/数字候補があるのに読みそのままの平仮名を選ぶ場合`1.25`点。`ください`など自然な平仮名は除外する。
- 順位事前分布: Mozc 1位は`0`点、2位は約`0.1525`点、3位は約`0.2417`点を減点する。

AI候補がMozc 1位を置き換える判定には、固定点差ではなく候補全体のsoftmax信頼度を使う。

```text
P(i) = exp(evidence(i) - max(evidence))
       / Σ exp(evidence(j) - max(evidence))
```

採用条件は次の通り。

1. 外部文脈信号が3文字以上、またはAI 1位とMozc 1位の共通接頭・接尾部分が合計4文字以上。
2. 原則としてAI 1位の`P(i) >= 0.80`、かつAI 1位とAI 2位のmarginも確認する。
3. 前後両側の文脈がある、または候補内部の共通部分が4文字以上なら、`P(i) >= 0.35`、AI根拠のMozc差`>= 1.80`、margin`>= 0.30`でも採用する。
4. `15日/十五日`のように数値部分だけが異なる同義候補は、差`>= 0.35`で同値表記として扱う。強い実務フレーム補正はmarginが僅差でも、読みそのまま候補でない場合に限り採用する。

3番目は`はな`のように候補が8件あり、正しい候補の絶対的な点差は大きいのにsoftmaxが候補数で薄まる場合の限定救済である。前方だけ・後方だけでは使わない。

候補内部文脈は読みの文字数ではない。たとえば`彼の顔の鼻は大きい`と`彼の顔の花は大きい`は、異なる1文字の周囲に8文字の共通部分がある。一方、`輸送して`と誤候補`油送して`の共通部分は3文字なので、短い外部文脈だけでは採用しない。

## パラメータ校正

実Mozc候補を使う非数詞194ケースと長句60ケースを、CPU INT8とGPU FP16、前後・前方のみ・後方のみ・短い前方・文脈なし・前の別文付きの6条件で測定した。AI 1位とMozc 1位が異なり、採否の判断が必要だった1,024件を校正対象にした。同一ケースの文脈違いが学習側と検証側へ跨がないよう、ラベルのSHA-256偶奇で固定分割した。

比較した方式は次の通り。

- Mozc差と次点差の固定しきい値
- 次点差に応じて必要Mozc差を指数曲線で変える方式
- AI 1位の絶対素点と1文字当たり素点
- 候補全体のsoftmax確率とエントロピー
- シグモイド積
- 二次特徴ロジスティック回帰（Mozc正解破壊を8倍重く学習）

絶対素点は候補長とCPU/GPUで尺度が動き、単独のしきい値には向かなかった。固定点差の試験範囲で最も保守的な設定でも、回復328件に対して厳密改悪28件だった。採用した方向制限付き非線形ゲートは回復286件、厳密改悪7件で、7件はすべて`見積もり`と`見積り`の表記差だった。観測上の意味破壊は0件である。

より保守的な`softmax >= 0.80`一本では回復178件、表記差2件まで減るが、実候補8件の`彼の顔の + はな + は大きい`が`P=0.624`となり鼻への修正を止める。そのため、前後両側または十分な候補内部文脈がある場合だけ、`P >= 0.35`かつMozc差`>= 1.80`の枝を残した。

算用数字の`1.00`点は、`一位`に対する`1位`のモデル素点差がCPU INT8で約`-0.704`、GPU FP16で約`-0.701`だったことから、必要な2位差`0.15`を超える最小値約`0.85`に余裕を持たせて設定した。

python scripts\explain_ranking.py `
